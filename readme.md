# AmbitionBox Company Scraper
A Python project to practise web scraping using Requests, BeautifulSoup, and Pandas.

## Features
- Extracts company names, ratings, review counts, categories, and locations.
- Stores the extracted data in a Pandas DataFrame.

## Requirements
Install the dependencies:
```bash
pip install -r requirements.txt
```

### Note
AmbitionBox may show a verification page, which can stop scraping. The scraper does not bypass website verification.
